# RnK V1.15 — Clarity, Navigation & Comprehension Pass

This revision responds to the simulated visitor critique of V1.14 without changing the approved Modern Conservation Editorial identity.

## Main changes

- Added a plain-English BERAE introduction before the technical definition.
- Added a plain-English SHGBEE explanation before the formal acronym expansion.
- Added contextual cross-links between Our Work and relevant Places & Stories sections.
- Added a compact homepage “What would you like to explore?” topic strip.
- Added an “Explore by Theme” jump-navigation system to Places & Stories so the growing story archive is easier to scan without turning the page into a generic filter interface.
- Added clear inquiry expectation copy on Get Involved: the form starts an inquiry and does not enroll, confirm a partnership, or create a commitment.
- Added stable section IDs and scroll margins so deep links land cleanly beneath the floating header.
- Versioned CSS and JavaScript files to V1.15 to reduce GitHub Pages cache confusion during review.

## Wix Studio path

All new interaction/layout patterns can be recreated with native Wix Studio elements: sections, stacks, grids, anchors, text links, responsive pills/buttons, and Wix Forms. No additional custom JavaScript is required for the new topic navigation or cross-linking.

## Content safeguards

No new impact figures, partner claims, donation mechanisms, volunteer commitments, or operational promises were introduced. Plain-language BERAE and SHGBEE explanations summarize concepts already supported by supplied RnK source materials.
