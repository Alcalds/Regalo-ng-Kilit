# Regalo ng Kilit Foundation — Editorial Chapters Hero V1

This project is a VS Code prototype used to compare a more formal, photography-first Hero direction with the earlier Living System and Kilit Lens concepts.

The homepage sections below the Hero remain based on RnK Homepage V2 and the staff-supplied source material reviewed on September 12, 2026.

## Hero principle
**Photography first. Interface second.**

The Hero uses four authentic RnK scenes and a restrained editorial chapter rail. The approved staff tagline is unchanged.

## Run locally
Open the folder in VS Code and launch `index.html` with Live Server.
