# RnK V1.12 — Contact Form + Modern Calamianes Showcase

## Homepage
The former three equal image cards in **From the Calamianes** were replaced with a responsive editorial mosaic: one large biodiversity feature and two supporting cards for People and Places. The layout uses normal CSS Grid and natural breakpoints only. In Wix Studio it can be rebuilt with one grid container, three image containers, overlays, text stacks, and links.

## Get Involved contact form
A general inquiry form was added with Full Name, Email Address, optional Mobile Number, optional Organization/Affiliation, Interest, and Message. The VS Code prototype does not store or transmit data to a backend; it prepares a `mailto:` message. In Wix Studio, recreate it using native Wix Forms and connect Wix automation/email notifications as required.

## Wix Studio mapping
- Homepage mosaic: Grid/containers + image fit Crop + gradient overlays + text stacks.
- Form: Wix Forms fields + submit button + Wix automation.
- No React, Tailwind, Bootstrap, GSAP, or custom-layout JavaScript is required.
